Getting started

  1. Place the WinBackup folder somewhere you can write to, then run WinBackup.exe. Avoid Program Files.
  2. Choose New Profile.
  3. Enter a name and choose a copy mode.
  4. On the Folders tab add at least one source and one destination, then choose Save.
  5. Choose Preview to see what will happen, then Run.

Use Preview the first time you run any profile, and after changing its folders, mode or filters.

The main window

The list on the left holds your profiles and profile folders. The panel on the right describes the selected item. The buttons above start common tasks.

Profiles

A profile stores everything about one job. Right-click the list for profile commands.

  • Folders group profiles. Create one with New Folder, then choose it on a profile's General tab. Deleting a folder moves its profiles to the top level.
  • Check boxes enable and disable profiles. Disabled profiles are skipped by Start All, by starting a folder, and by the scheduler. They can still be started one at a time.
  • Deleting a profile never removes backed up files.

Folders

  • A profile can have several source and several destination folders. Every used source is processed with every used destination.
  • Clear Use to leave a folder out without removing it.
  • Add folders with Add, by typing with Add Text, or by dragging them from Explorer.
  • Windows environment variables work, for example %USERPROFILE%\Documents. Network paths such as \\server\share\folder work too.
  • Create a subfolder for each source keeps several sources apart in the destination. An empty subfolder name uses the source folder's name. Mirror needs this option when there is more than one source.
  • Sources and destinations cannot be the same or contain each other.

Filters

Skip development files

ChoiceSkips
Build outputbin and obj folders that sit beside a project file such as .csproj or .vcxproj. Other folders with these names, such as those belonging to installed programs and games, are still copied.
Visual Studio working files.vs folders, *.suo files and project .user files
Git data.git folders. The copy then has no repository history, including commits that exist only on your computer.

All choices are off until you select them. On their own, like other filters, they leave copies that already exist in a destination untouched.

Remove skipped development files from the destination

  • Works only in Mirror mode and is off until you select it.
  • Deletes what the three choices above skip, where it already exists in a destination. Each item is listed in Preview as a deletion with the reason Skipped development file.
  • Only the choices you selected are cleaned up. Items matched by your exclude patterns, or left out by your include patterns, are kept. Links and junctions are kept.
  • Deletions follow the profile's Safety settings. With the Recycle Bin, space is freed only after you empty it. Items that cannot go to the Recycle Bin are kept and reported.
  • A large first cleanup may trigger the safeguard. Check the list in Preview, then run from there. Until then, scheduled and direct runs change nothing for that folder pair.

Patterns

Enter one pattern per line. * matches any text and ? matches one character. Matching ignores upper and lower case.

PatternMatches
*.tmpEvery file ending in .tmp
cacheAnything named cache (in a folder box, every folder named cache)
Projects\OldThe path Projects\Old inside a source
*\objIn a folder box, folders named obj at any level
  • A pattern containing a backslash is compared with the path, otherwise with the name.
  • An empty include box includes everything.
  • With Include folders, only files inside matching folders are processed.
  • Exclude rules win over include rules.
  • Filtered items are ignored on both sides. Mirror and Sync never delete a filtered file. A folder that still holds filtered files is kept.

Safety

Removed and replaced files

ChoiceEffect
Recycle BinThe default. Works on local fixed drives and for paths shorter than 260 characters. When a file cannot go to the Recycle Bin it is left in place and reported as an error. Windows may ask for confirmation if a file is too large for the Recycle Bin.
Version folderFiles are moved to version folder\profile\date_time\original folder\.... Works on any drive and with long paths. You can limit the number of version sets kept.
Delete permanentlyFiles cannot be recovered.

Empty folders are removed directly. A folder is only removed when it is empty.

Safeguards

  • If a source folder is not available, nothing is changed for it.
  • If one side contains no files and files would be deleted from the other, the folder pair is stopped.
  • If more files would be deleted than your limit allows, the folder pair is stopped. The default is more than 50% and more than 10 files.
  • A stopped pair can be run from the Preview window after you confirm. Scheduled and direct runs never override a safeguard.
  • If a folder cannot be read, the matching items on the other side are not deleted.
  • Links and junctions are not followed and are never deleted.
  • A copy is written to a temporary file first. The existing file is replaced only after the copy succeeds.
  • $RECYCLE.BIN and System Volume Information at the top of a drive are ignored.

Backup mode

  • Each run creates a new folder or ZIP file in every destination.
  • The name may use {profile}, {date} and {time}. A number is added if the name already exists.
  • Keep the newest sets how many complete backups remain. 0 keeps all. Older backups are deleted permanently.
  • A backup is complete only when it finished without errors, contains files, and nothing was skipped. Old backups are removed only after a complete backup.
  • WinBackup removes only backups it recorded itself. Other files in the destination are left alone. If the config folder is lost, earlier backups are no longer removed automatically.
  • A ZIP file appears only when it is finished. ZIP passwords and split archives are not available.

Sync mode

Sync keeps one destination and its sources up to date in both directions. After each run it remembers the matching files, which lets it tell a new file from a deleted one.

  • On the first run nothing is deleted. Files present on one side are copied to the other.
  • A file changed on one side is copied to the other.
  • A file deleted on one side and unchanged on the other is deleted there.
  • A file changed on one side and deleted on the other is restored.
  • A conflict occurs when both copies differ and it is unclear which should win. Choose to skip and report it, or let the newer file, the source, or the destination win. In Preview you can decide for each item.
  • If the destination folder disappears after a sync, nothing is changed.

Preview

  • Preview compares the folders without changing anything. Only items that need attention are listed.
  • Preview compares names, sizes and dates and does not read file contents, so it is much quicker than copying.
  • The totals above the list show the files, folders and size compared on each side, what the filters skipped, and the time taken. A skipped folder counts once and its contents are not counted.
  • Use Show to list copies, deletions or skipped items.
  • Each row is colored by its action: green copies to the destination, blue copies to the source, red deletes in the destination, purple deletes in the source, and yellow is skipped. A legend is shown below the list. A selected row shows the selection color instead.
  • Select one or more rows and right-click to change their action.
  • Warnings, unreadable folders and safeguards appear below the list.
  • Run carries out the list as shown. Use Refresh if files or the profile have changed since the preview was made. Refresh uses the latest saved profile.

Running jobs

Jobs run in the background, one at a time. Further jobs wait in line. The panel at the bottom of the main window shows progress and has Pause and Cancel. Cancel stops the current job and clears the line. A partly copied file is removed.

Scheduler

ChoiceRuns
OnceAt the start date and time
IntervalEvery set number of minutes, counted from the start date and time
DailyEvery day at the time
WeeklyOn the selected days at the time
MonthlyOn the day of the month at the time. Day 31 means the last day of shorter months.
  • Schedules work only while WinBackup is running. Keep it in the system tray. WinBackup does not add itself to Windows startup.
  • A run more than five minutes late is treated as missed. Select Run a missed schedule to run it anyway.
  • Also run when WinBackup starts works with any choice, including Manually.

Reports and logs

Reports lists every run with its result. Select a run to see each item, and use Show to see only errors, or errors and warnings.

The Log Viewer shows the daily application log with a text filter.

Logs and reports older than the number of days under Settings, Logging are removed at startup.

Email notification

Under Settings, Email enter your SMTP server, port, sender and recipients, choose when to send, and use Send Test.

  • TLS uses STARTTLS, normally on port 587. Servers that only accept implicit TLS on port 465 are not supported.
  • Services that require browser sign-in are not supported. Some providers offer an app password for SMTP.
  • The password is encrypted for your Windows account. Enter it again after moving WinBackup to another computer or user.

Troubleshooting

Message or problemWhat to do
A file is being used by another processClose the program using it. Files locked by another program cannot be copied.
Access is deniedCheck that your account may read the source and write the destination.
This drive has no Recycle BinOn the Safety tab, choose a version folder.
Nothing was changed (safeguard)Open Preview, check the deletions, then run from there if they are right.
A scheduled run did not happenCheck that WinBackup was running and the profile is enabled, then look in the log.
Mapped drive not foundUse the network path instead of the drive letter.
Files copied again after a clock changeSome drive formats store local time. Run the profile once to bring the times up to date.

File permissions and alternate data streams are not copied. Folder dates are not preserved.
